# Perigon Datasets - Free & Open-Source

This repo gives you access to all the freely available Perigon datasets extracted directly from the [Perigon API](https://perigon.io/docs).

Feel free to use this for AI training, fine-tuning, educational purposes, or commercial use. Perigon provides contextual intelligence through its API, offering real-time access to events happening around the world.
